## `$ cat ~/.featured-achievements.md`

- 🔒 **In-house code security platform:** Built and own an end-to-end platform (SAST, SCA, SBOM, secret and container scanning) on **Python + Temporal** with a **Backstage** portal. It replaced a commercial SaaS tool and saves **₹50L+ per year**.
- 📦 **Helm standardisation:** Reusable umbrella Helm charts that now power **150+ microservices**.
- 🔄 **CI and progressive delivery:** Scalable CI on **GitHub Actions**, GitOps with **ArgoCD**, and canary releases with **Argo Rollouts** that roll back automatically on latency and error-rate metrics.
- ☁️ **AWS to GCP migration:** A key role in moving core infrastructure to GCP, including the landing zone architecture, which cut costs.
- 🛠️ **Self-serve infrastructure:** Modernised IaC pipelines so teams provision infrastructure without waiting on the cloud team.
- 🧪 **Dynamic staging environments:** On-demand Kubernetes staging using **ArgoCD** and gateway header routing.
- 📊 **Unified telemetry:** Self-hosted, company-wide observability on the **Grafana LGTM** stack.
- ⚡ **Self-hosted GitHub runners:** Actions runners on Kubernetes (ARC), cutting CI cost and queue time.
- 🤖 **AI-powered DevOps assistant:** Analyses Terraform errors and automates fixes. Won a company-wide hackathon.
